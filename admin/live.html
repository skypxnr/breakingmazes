Live Control

Broadcast a live YouTube stream on the public site

Broadcast Settings

For a scheduled live stream, use https://www.youtube.com/embed/VIDEO_ID. For a channel-wide live, use https://www.youtube.com/embed/live_stream?channel=CHANNEL_ID.
Preview Live Page ↗

How to get the YouTube Live URL

  1. Go to YouTube Studio → Create → Go Live.
  2. Once the stream is created, copy the Video ID from the watch URL: youtube.com/watch?v=VIDEO_ID.
  3. Paste the embed URL above: https://www.youtube.com/embed/VIDEO_ID.
  4. Set status to Live and click Save & Publish.
  5. The public site will now show a red LIVE badge in the header linking to /live.html.
